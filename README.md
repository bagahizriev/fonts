# type.library

Личная библиотека веб-шрифтов на React и GitHub Pages. Список хранится в `public/fonts.json`, а загруженные файлы — в `public/fonts/`.

## Запуск локально

```sh
npm ci
npm run dev
```

## Публикация на GitHub Pages

1. Создайте GitHub-репозиторий и отправьте в него этот проект.
2. Убедитесь, что основная ветка называется `main` (или измените ветку в `.github/workflows/deploy.yml`).
3. В настройках репозитория откройте **Settings → Pages** и выберите **GitHub Actions** как источник публикации.
4. При каждом push в `main` workflow соберёт сайт и опубликует его на GitHub Pages. Его адрес появится в разделе **Settings → Pages**.
5. Откройте сайт и настройте владельца, репозиторий и ветку, куда приложение будет сохранять данные. Обычно это сам репозиторий сайта.

Для локальной проверки production-сборки:

```sh
npm run build
npm run preview
```

## Управление библиотекой

Список читается напрямую из `public/fonts.json` опубликованного репозитория. Добавление и удаление выполняются браузером через GitHub Contents API — отдельный сервер не нужен. При добавлении файла приложение загружает его в `public/fonts/`, а затем обновляет JSON; ссылки на CSS сохраняются как URL.

Перед изменением списка приложение перечитывает актуальный JSON у GitHub. Если файл успел измениться между чтением и записью, операция повторяется с новым SHA и сохраняет параллельно добавленные записи.

Для записи создайте **fine-grained personal access token** с доступом только к нужному репозиторию и разрешением **Contents: Read and write**. Вставьте токен в настройках сайта. Он хранится в `localStorage` только этого браузера и не включается в код, JSON или workflow. Удалите токен из настроек, чтобы убрать его из браузера, и отзовите его в GitHub, когда он больше не нужен.

**Важно:** это удобно для личного сайта, но не равно безопасной серверной авторизации. JavaScript сайта может читать токен из `localStorage`; вводите его только на доверенном экземпляре сайта, не используйте токен с широкими правами и не передавайте ссылку на браузер/компьютер с сохранённым токеном. Для просмотра коллекции токен не требуется.

Поддерживаются отдельные файлы WOFF, WOFF2, TTF и OTF размером до 10 МБ, а также HTTPS-ссылки на таблицы стилей веб-шрифтов (например, Google Fonts). Загрузка нескольких файлов и извлечение начертаний пока не реализованы.
